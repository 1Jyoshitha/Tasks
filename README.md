
# React Task Collection 🧩

This repository is a collection of mini-projects and tasks created to practice and demonstrate core concepts of **ReactJS**. Each task is organized in its own folder (e.g., `task1`, `task2`, etc.) and focuses on different frontend fundamentals such as components, state management, props, hooks, and more.

---

## 📁 Directory Structure

Each folder represents an individual React project:

```
Tasks/
├── task1/        # Simple static UI with components
├── task2/        # Basic dynamic content (e.g., counter)
├── task3/        # Form handling with input elements
├── task4/        # Conditional rendering or list mapping
├── task5/        # Calculator using useState
├── task6/        # (Possibly routing, API calls, or more advanced hooks)
└── ...
```

> ⚠️ You can open and run each folder as an individual Create React App project.

---

## 🛠 Technologies Used

- ReactJS (with hooks)
- JavaScript (ES6)
- HTML & CSS
- Node.js and npm

---

## 🚀 How to Run a Task

1. **Clone the Repository:**
```bash
git clone https://github.com/1Jyoshitha/Tasks.git
cd Tasks
```

2. **Navigate to a specific task folder:**
```bash
cd task3
```

3. **Install dependencies and run:**
```bash
npm install
npm start
```
